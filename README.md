# LearnHub — Udemy-inspired course marketplace demo

## Run it
1. Extract the ZIP.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.

## Features
- Responsive course marketplace layout
- Local course thumbnail illustrations in `images/` (no external image host needed)
- Global course search that works while typing and on Enter/Search
- Category filters and bestseller/new-release filters
- Wishlist with live count
- Course detail/enrolment demo modal
- Demo login and sign-up modals

## Files
- `index.html` — page structure
- `style.css` — visual styling and responsive rules
- `script.js` — course data, rendering, filtering, wishlist, and demo interactions
- `images/` — course thumbnails and fallback image

## Notes
This is a front-end demo, not a production learning platform. Authentication, payments, user accounts, and course progress are not connected to a backend. Google Fonts are optional; the site and course thumbnails work without them.
